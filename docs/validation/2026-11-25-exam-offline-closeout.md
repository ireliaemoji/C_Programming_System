# 2026-11-25 正式考试收尾验收

- A 机 Windows，工作区包含当前未提交改动。API 使用项目 Docker MySQL 8.4.9，Unity 2022.3.62f3c1。

| 场景 | A 机结果 |
|---|---|
| API 编译 | dotnet build 通过，0 警告、0 错误 |
| Unity 脚本编译 | Unity batchmode 导入和脚本编译通过，退出码 0 |
| 服务端时间 | /api/exams 和开考响应返回数据库 serverNow，答卷响应返回 endAt |
| 到期自动交卷 | 建立 4 秒考试，学生开考后退出。等待 7 秒，教师答卷列表显示同一学生为 Submitted，得分按已保存答案计算 |
| 答案 revision | 服务端保存答案时记录 revision，代码按版本拒绝旧写入，重复相同版本可幂等成功。独立旧版本 HTTP 场景待 B 机复验 |
| 本地草稿 | 客户端使用 Application.persistentDataPath/ExamDrafts，答案写入临时文件后原子替换 |
| 退避补传 | 客户端尝试 1、2、5、10、30、60 秒间隔，截止前补传，服务端确认后删除队列项 |
| 截止后行为 | 客户端查询答卷状态，服务端截止后的答案写入返回失败，不继续补传 |

B 机仍需按同一提交和结构迁移重建独立数据库，实际断网、重启应用、截止前恢复和截止后恢复结果由 B 端补记。当前 A 机未执行物理断网实测，API 级到期结算已验证。
