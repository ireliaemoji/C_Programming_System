# Unity 可用 ArtAssets 生成提示词

这些提示词面向 Image 2.0 生成“可进入 Unity 资源库”的独立视觉资产，不生成完整页面截图。真实中文、数字、进度、状态、列表和交互全部由 Unity 组件与代码生成。

## 统一前缀

```text
现代 C 语言在线考试与练习平台 UI 视觉资产，深海军蓝、蓝色、浅灰蓝和白色配色，专业教育软件风格，简洁、稳定、清晰，正面平视，适合 Unity Canvas，独立资产，干净边缘，高分辨率，透明背景或纯色背景，不能包含任何文字、数字、按钮标签、表格、进度条、百分比、姓名、考试数据或完整页面布局。
```

## 统一负面提示词

```text
不要完整网页截图，不要完整 App 截图，不要中文，不要英文，不要数字，不要乱码，不要按钮文字，不要进度条，不要圆形进度，不要表格内容，不要设备外框，不要浏览器窗口，不要透视，不要水印，不要多余装饰，不要复杂背景，不要把多个页面拼在一张图中。
```

## 生成顺序

建议分批生成：

1. 第 1 批：01–10，背景、面板和按钮；这些资源需要单独检查透明边缘和九宫格可用性。
2. 第 2 批：11–15，图标；可以按“学生导航”“教师导航”“通用操作”“状态图标”分别生成，不建议一次生成所有图标。
3. 第 3 批：16–19，空状态和代码区背景；每个插画单独生成。
4. 第 4 批：20–22，头像和 Logo。

## Unity 接入要求

- 面板和按钮导入为 Sprite 后设置 `Sprite Mode = Single`，再设置 `Sprite Editor > Border`，使用 `Image Type = Sliced`。
- 图标图集设置 `Sprite Mode = Multiple`，使用 Sprite Editor 切片；不要把整张图集直接拖进 Image。
- 背景不包含 Header、SideNav、BottomNav 和内容卡片。
- 文本、进度条、圆环、考试倒计时、列表、表格和状态由 Unity 控件与代码生成。
- 同一组图标和按钮必须保持统一尺寸、统一透明边距和统一视觉线宽。
