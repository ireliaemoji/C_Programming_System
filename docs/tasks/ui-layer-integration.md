# UI 页面预制体交接

日期：2026-11-24；替代此前的根容器/动态工厂首版。

## 当前实现

`client/Assets/Resources/UI/UiRoot.prefab` 保存 PC 2560×1440 与手机 1080×2160 完整布局，使用已确认的 ArtAssets。登录、学生首页、考试列表、考试、成绩、教师总览、班级、题库、组卷、设置及交卷确认控件均在 prefab 中；手机使用题号抽屉。业务层只实例化一次根预制体、绑定控件，并克隆数据列表条目模板。

设计、锚点、缩放规则、素材和编辑器工具说明见 [基准布局](../design/ui-prefab-reference-layout.md)，实际验证范围见 [验收记录](../validation/2026-11-24-ui-reference-layout.md)。常规外观修改在 Prefab Mode 中完成；`CExam/UI/Rebuild reference prefab` 会覆盖手动布局，只有需要恢复源码基准时才执行。

1. 在已打开的正式 `SampleScene` 退出旧 PlayMode，再运行；确认生成新版完整 prefab，Console 无新增错误。
2. 使用本机 API 验证登录、教师班级/题库上传/组卷、学生开考/选择/自动保存/交卷/成绩返回。
3. PC 1280×720、1440×900、1920×1080、2560×1440 及超宽屏；手机 360×800、390×844、430×932、1080×2160 检查可读性、滚动、题号抽屉、软键盘和 SafeArea。
4. B 端仍按同一版本独立验收；离屏渲染或隔离播放器通过不能替代 B 和真机结果。

学生题库/自主练习、程序评测、教师评分等尚无本轮实现的业务仍不假装可用。PC 最终 2560×1440 背景原图替换与正式移动端字体覆盖需要后续发布验收。
